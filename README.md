# GitHub Explorer

Aplicação web que consulta a API pública do GitHub para encontrar usuários e ver seus repositórios.

## Funcionalidades

- **Buscar usuários:** pesquise pelo username ou pelo nome; os resultados aparecem enquanto você digita.
- **Ver o perfil do usuário:** avatar, seguidores, seguidos, e-mail e bio.
- **Listar os repositórios do usuário:** ordenados por estrelas, do mais para o menos popular.
- **Mudar a ordenação:** mais estrelas, menos estrelas, nome (A–Z) ou atualizados recentemente.
- **Ver os detalhes de um repositório:** nome, descrição, estrelas, linguagem e link para abrir no GitHub.
- **Compartilhar links:** a busca e a ordenação ficam no endereço da página.
- **Usar no celular:** o layout se adapta a telas pequenas.
